# AutoReply クイックスタート

## 1. 導入する

`AutoReply.cs` を `oxide/plugins/AutoReply.cs` に配置する。追加プラグイン・権限設定は不要。

## 2. 案内を編集する

初回ロードで作成される `oxide/lang/ja/AutoReply.json` と `oxide/lang/en/AutoReply.json` の返信内容を、自分のサーバーに合わせて編集する。特に Discord の URL は仮の案内先なので変更する。JSON のキーは変えない。

変更後、サーバーコンソールまたは RCON で再読み込みする。

```text
oxide.reload AutoReply
```

## 3. チャットから使う

```text
/lang ja
!vip
!discord
!kit
!rules
```

各トリガーは1件ずつ送信する。入力者本人だけに案内が届き、一致したトリガーは通常のチャットへ流れない。英語にする場合は `/lang en`。

## 更新・撤去

更新前に本体と言語ファイルをバックアップする。撤去はサーバーコンソールで `oxide.unload AutoReply` を実行してから `.cs` を配置先から移動する。

仕様・出典・検証範囲は [README](README.md) を参照。
