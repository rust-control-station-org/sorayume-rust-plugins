# CheckJump クイックスタート

## 1. 導入と権限設定

`CheckJump.cs` を `oxide/plugins/CheckJump.cs` に配置する。追加プラグイン・独自設定ファイルは不要。

管理者以外に操作を許可する場合、サーバーコンソールまたは RCON で付与する。

```text
oxide.grant user <SteamID> checkjump.use
```

## 2. ゲーム内チャットで実行する

```text
/lang ja
/jmp <SteamIDまたは名前> 20
```

対象が現在位置から20m上へ移動する。高さを省略しても20m。落下によって対象が負傷・死亡する可能性があるため、対象と周囲を確認してから実行する。高さには通常の有限数を指定する。

## 更新・撤去

本体と言語ファイルをバックアップしてから更新し、必要ならサーバーコンソールで `oxide.reload CheckJump` を実行する。撤去は `oxide.unload CheckJump` の後に `.cs` を配置先から移動する。

入力制限の未実装事項、出典・検証範囲は [README](README.md) を参照。
