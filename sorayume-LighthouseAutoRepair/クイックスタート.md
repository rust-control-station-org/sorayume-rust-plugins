# LighthouseAutoRepair クイックスタート

コマンド例はサーバーコンソールまたは RCON で実行する。

## 1. 導入する

`LighthouseAutoRepair.cs` を `oxide/plugins/LighthouseAutoRepair.cs` に配置する。

**既定ではワイプから24時間で灯台を自動修理する。導入時点で期限を過ぎていれば、ロード直後に修理する。** 最初は状態だけ確認したい場合、配置前に `oxide/config/LighthouseAutoRepair.json` を次の内容で作成する。

```json
{
  "Auto repair enabled": false,
  "Hours after wipe before auto repair": 24,
  "Announce auto repair in chat": true
}
```

## 2. 状態を確認する

```text
lighthouserepair.status
```

灯台、ワイプ時刻、自動修理の期限、ディープシーの状態が表示される。

## 3. 自動修理を有効にする

`oxide/config/LighthouseAutoRepair.json` の `Auto repair enabled` を `true` にし、必要に応じて期限の時間数を変更する。

```text
oxide.reload LighthouseAutoRepair
lighthouserepair.status
```

期限前は1分ごとに確認する。灯台がない場合やディープシーが無効の場合は何もしない。

## 4. 期限を待たずに修理する場合

```text
lighthouserepair.repair
```

素材を消費せず全灯台を修理し、ゲーム本体の処理でディープシーの開放を進める。修理済みなら何も変えない。F1 コンソールでは管理者か `lighthouseautorepair.admin` 権限が必要。

```text
oxide.grant user <SteamID> lighthouseautorepair.admin
```

## 更新・撤去

本体・設定・言語ファイルをバックアップしてから更新する。撤去は `oxide.unload LighthouseAutoRepair` の後に `.cs` を配置先から移動する。修理済みの灯台はそのまま残る。

全設定・制限・検証範囲は [README](README.md) を参照。
