# MonumentReset クイックスタート

モニュメントの箱・NPC・パズルを手動でリセットする。実行するとワールドの状態が変わる。

## 1. 導入と権限設定

`MonumentReset.cs` を `oxide/plugins/MonumentReset.cs` に配置する。

ゲーム内から操作する管理者以外のプレイヤーには、サーバーコンソールまたは RCON で権限を付与する。

```text
oxide.grant user <SteamID> monumentreset.admin
```

## 2. 対象の ID を調べる

ゲーム内チャット:

```text
/mreset list
```

サーバーコンソール・RCON の場合は `monumentreset.list`。一覧に出る ID をそのまま使う。地下トンネル・海底ラボ・ディープシーは対象外。

## 3. リセットする

```text
/mreset <ID> loot
```

パズルに属さないルート箱・ドラム缶などをリセットする。`puzzle` はパズルと所属する箱・NPC、`npc` は独立した NPC、`crate` は独立したハッキング箱。種類を省略するか `all` を指定するとすべてが対象。

```text
monumentreset.run <ID> loot
```

こちらはサーバーコンソール・RCON 用。同じ処理を行う。

既定では範囲内に警告し、10秒後に実行する。プレイヤーが範囲内にいても実行するので、事前に状況を確認する。寝ているプレイヤーがいるパズルはスキップする。

## 4. 秒読み中に取り消す

```text
/mreset cancel <ID>
```

サーバーコンソール・RCON では `monumentreset.cancel <ID>`。ID を省略すると秒読み中の予約をすべて取り消す。実行済みのリセットは取り消せない。

## 設定・更新・撤去

警告や待ち時間は `oxide/config/MonumentReset.json` を編集し、`oxide.reload MonumentReset` で反映する。更新前に本体・設定・言語ファイルをバックアップする。

撤去は `oxide.unload MonumentReset` の後に `.cs` を配置先から移動する。秒読みは取り消されるが、実行済みのリセットは元に戻らない。

対象の分類・制限・検証範囲は [README](README.md) を参照。
