# PowerPlantFuseRefill クイックスタート

コマンド例はサーバーコンソールまたは RCON で実行する。

## 1. 導入する

`PowerPlantFuseRefill.cs` を `oxide/plugins/PowerPlantFuseRefill.cs` に配置する。

**既定ではロード直後に目標10本まで補充し、以後3時間ごとに不足分を補充する。** 先に状態だけ確認したい場合は、配置前に `oxide/config/PowerPlantFuseRefill.json` を次の内容で作成する。

```json
{
  "Auto refill enabled": false,
  "Refill interval seconds": 10800,
  "Target fuse count": 10,
  "Refill when plugin loads (auto refill only)": true
}
```

## 2. 状態を確認する

```text
powerplantfuse.status
powerplantfuse.list
```

本数、電力網のステージ、推定寿命を表示する。対象のパワープラントがないマップでは補充できない。

## 3. 補充する

```text
powerplantfuse.fill 10
```

稼働中のヒューズが10本になるまで不足分だけ挿入する。引数なしなら設定の目標本数。上限はマップの総ソケット数。

## 4. 自動補充を切り替える

```text
powerplantfuse.auto on
powerplantfuse.auto off
```

実行した設定は保存される。F1 コンソールから使う場合は管理者か `powerplantfuserefill.admin` 権限が必要。

```text
oxide.grant user <SteamID> powerplantfuserefill.admin
```

## 更新・撤去

本体・設定・言語ファイルをバックアップしてから更新する。設定編集後は `oxide.reload PowerPlantFuseRefill`。

撤去は `oxide.unload PowerPlantFuseRefill` の後に `.cs` を配置先から移動する。挿入したヒューズはゲーム内に残る。

全設定・制限・検証範囲は [README](README.md) を参照。
