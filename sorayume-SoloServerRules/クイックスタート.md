# SoloServerRules クイックスタート

## 1. 導入する

`SoloServerRules.cs` を `oxide/plugins/SoloServerRules.cs` に配置する。追加プラグイン、独自設定、権限付与は不要。

## 2. 適用されるルールを確認する

- Code Lock は所有者本人だけがコードを入力できる。
- 寝袋・ベッドは自分にだけ割り当てられる。
- 管理者にも同じ制限が適用される。

既存の認証情報・割り当てを遡って取り消すことはない。以後のコード入力・割り当て操作を制限する。

## 3. 表示言語を選ぶ

ゲーム内チャットで `/lang ja` または `/lang en` を実行する。拒否された操作の案内がその言語で表示される。

## 更新・撤去

更新前に本体と言語ファイルをバックアップする。更新後は必要ならサーバーコンソールまたは RCON で `oxide.reload SoloServerRules` を実行する。

撤去は `oxide.unload SoloServerRules` の後に `.cs` を配置先から移動する。

詳細な仕様・出典・検証範囲は [README](README.md) を参照。
