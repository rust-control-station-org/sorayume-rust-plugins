# Wabi 管理者クイックスタート

全設定・保存データの扱い・検証範囲は [README](README.md) を参照。

このドキュメントは、Rustサーバー管理者が sorayume-wabi を使って補填を配布するための最短手順です。\
コマンドはすべてサーバーコンソール(または RCON)から実行します。

## 0. 前提

- `Wabi.cs` を `oxide/plugins/` に配置し、プラグインがロードされていること(`oxide.reload Wabi`)。
- サーバーコンソール・RCON は管理操作を実行できる。プレイヤーの F1 コンソールからはサーバー管理者(`IsAdmin`)か `wabi.admin` 権限が必要。

```
oxide.grant user <steamid64> wabi.admin
```

## 1. 補填キャンペーンを作成する

```
wabi.new
```

IDを省略すると日時から自動生成されます。特定のIDを付けたい場合は `wabi.new <id>` を使います。
この時点ではまだプレイヤーは受け取れません(受付前の状態)。

## 2. 配布するアイテムを設定する

```
wabi.item wood 1000
wabi.item stones 500
wabi.item metal.refined 50
```

同じ shortname を再度指定すると数量が上書きされます。削除したい場合は:

```
wabi.remove metal.refined
```

## 3. 対象プレイヤーを設定する

全員に配布する場合:

```
wabi.target all
```

特定のプレイヤーだけに配布する場合:

```
wabi.target add 76561198000000000
wabi.target add 76561198000000001
```

個別対象リストをやり直したい場合:

```
wabi.target clear
```

(`clear` の直後は誰も受け取れない状態になるので、必ず `add` で追加してください。)

## 4. 有効期限を設定する(任意)

デフォルトは設定ファイルの `Default expiry hours`(初期値3時間)が使われ、`wabi.start` した瞬間からカウントされます。
変更したい場合:

```
wabi.expire 3h
wabi.expire 30m
wabi.expire 2030-01-01 23:59
wabi.expire default
```

## 5. 受付を開始する

```
wabi.start
```

アイテム・対象・期限のチェックが行われ、問題なければ受付が始まります。
プレイヤーはゲーム内チャットで `/wabi` と入力すると受け取れます。

## 6. 状況確認

現在のキャンペーン全体の状況:

```
wabi.list
```

特定プレイヤーの受領状況:

```
wabi.check 76561198000000000
```

## 7. 受付を停止する

```
wabi.stop
```

停止後はアイテム・対象・期限の再編集が可能になります(受付中は編集できません)。

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| `受付中の補填は編集できません` と表示される | 先に `wabi.stop` を実行してから編集してください。 |
| `開始できません: 存在しないitem shortnameです` | shortname の綴りを確認してください(小文字・正式なアイテムID)。 |
| `開始できません: 個別対象モードですが対象SteamIDが0件です` | `wabi.target add <steamid64>` で対象を追加するか、`wabi.target all` に切り替えてください。 |
| マップワイプ後にキャンペーンが自動停止していた | 仕様です。ワイプ検知時に Season ID が更新され、旧キャンペーンは自動停止します。`wabi.new` から作り直してください。 |
| プレイヤーへの再付与が必要になった | `wabi.reset <steamid64>` で受領記録を削除できますが、**既に渡したアイテムは回収されません**。二重付与の危険があるため、本当に必要な場合のみ使用してください。 |

## コマンド早見表

```
wabi.help
wabi.new [id]
wabi.item <shortname> <amount>
wabi.remove <shortname>
wabi.target all
wabi.target add <steamid64>
wabi.target remove <steamid64>
wabi.target clear
wabi.expire default
wabi.expire <3h|30m|180m>
wabi.expire <yyyy-MM-dd HH:mm>
wabi.start
wabi.stop
wabi.list
wabi.check <steamid64> [campaignId]
wabi.reset <steamid64> [campaignId]
```
